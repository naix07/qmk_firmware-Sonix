# miller GM807

![miller GM807 Hotswap RGB](https://imgur.com/wlTaS0c.png)

Also sold as:

- Ajazz K870T
- Flashquark Falcon Elite
- Keebio Hotswap TKL Bluetooth Keyboard w/RGB
- Rakk Lam-Ang (Pro)

Built and tested on rev 1.0 board. NEWER BOARD REVISIONS ARE NOT COMPATIBLE.

## Bluetooth Control
The keyboard can connect up to 3 devices at the same time.

`Fn`+`P`: Enter Pairing Mode

`Fn`+`Q/W/E`: Select profile 1/2/3

`Fn`+`Tab`: Wired/Bluetooth mode

`Fn`+`B`: Battery Level (Green/Yellow/Orange/Red)

## Multimedia Control
`Fn`+`F6`: Previous Track

`Fn`+`F7`: Play/Pause Track

`Fn`+`F8`: Next Track

## RGB Backlight Control

`Fn`+ `→`: Next animation

`Fn`+ `←`: Previous animation
 
`Fn`+ `↑`: Increase brightness

`Fn`+ `↓`: Decrease brightness

`Fn`+ `Ins`: Increase animation speed

`Fn`+ `Del`: Decrease animation speed

`Fn`+ `Home`: Increase saturation

`Fn`+ `End`: Decrease saturation

`Fn`+ `PgUp`: Next hue

`Fn`+ `PgDn`: Previous hue
